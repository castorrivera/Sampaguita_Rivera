# Activity 3: Finding the hypotenuse of a right triangle

## Description: The program calculates the hypotenuse of a right triangle using the math module

## How to run: First you must enter a value for leg a and leg b and the program will calculate the hypotenuse of the given values

## Inputs needed: You must input the values of leg a and leg b of a right triangle

## Example output: a = 3, b = 5, "the hypotenuse of 3 and 5 is 5.83"
